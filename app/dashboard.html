Methods

How MODIS and VIIRS are harmonized

  1. Clean: keep vegetation fires (type 0), drop low-confidence hotspots. Core calendar uses MODIS Aqua, VIIRS S-NPP and VIIRS NOAA-20.
  2. Grid: assign each hotspot to a 0.1° cell (about 11 km). Any area is a set of cells.
  3. Match scales: for each calendar month, compare VIIRS to MODIS over 2012–2018, when both flew. That monthly ratio scales earlier MODIS to the VIIRS level.
  4. Validate: test on 2019–2025, years not used to fit, against a baseline that applies no scaling.

How “unusual” is decided

  • Each month is ranked against the same calendar month in 2003–2025 (complete archive years), using harmonized values, always. The date filter you choose never changes this baseline.
  • The year being checked is left out of its own baseline.
  • At least 10 comparison years are needed. Otherwise the app says “Insufficient historical data” and flags nothing.
  • Unusual means above the 90th percentile. One high month does not make a trend.
  • Raw data is never used for percentiles, because it contains the 2012 sensor jump.

Archive vs provisional

Provisional dates are shown only when verified NRT source records are available. NRT observations can be revised when archived data arrives.

Validation (2019–2025)

Hotspot counts are not burned area. They show where satellites detected active fire, not how much land burned.
